# Offline single-file verdict experiment, 23 November 2026

Exploratory candidate comparison. Use the 24 existing synthetic sources for training only. Repeat the previous CPU CNN, six epochs, six balanced source/codec pairs per step. The sole training change for the challenger is adding 0.5 times the mean softplus of (baseline logit minus codec logit) within contemporaneous matched crops. Same seed, order, optimizer and preprocessing. Score a file by averaging six four-second window logits using that file alone.

Generate 32-second stereo 16-bit procedural compositions with six new sound recipes. Use detuned saw harmonics and FM reeds for threshold calibration. Reserve pulse-width leads, inharmonic mallets, vibrato strings and noise-excited resonators for evaluation. Cross two settings each of attack, sustain, brightness and event density in all 16 combinations per recipe. Use one composition per cell. Balance 44.1/48 kHz by parity of the factor bits. Seeds and voices are distinct across recipes. All share a sequencer and constitute six recipe groups. For each composition use the baseline plus the original six MP3/AAC settings, at native rate; verify frame count and score the same six crops starting at 0, 5, 10, 16, 22 and 28 seconds. Predetermine the generator and runner before scoring. Keep audio, model checkpoints and per-file evidence on schwarz.

For each model separately take the largest clean calibration score as the upper cutoff and the empirical fifth percentile of encoded calibration scores (lower order statistic) as the lower cutoff. If the two leave a gap in the reverse order, use their midpoint for both. Above the upper cutoff report likely lossy, below the lower report no evidence, and otherwise abstain. Persist the thresholds before scoring any evaluation recipe. No updates using evaluation outputs.

Report the complete three-way counts by clean/codec state, recipe and overall. Detection = flagged / all encoded. False alerts = flagged / all clean. Class-balanced coverage = the mean of the clean and encoded non-abstention rates. For a pilot win require strictly fewer clean false alerts than the baseline, at least 50% encoded detection and 60% balanced coverage, and no more than five percentage points lost versus baseline on either detection or balanced coverage. These are exploratory decision criteria. If tied at zero false alerts, report the tie. Report fixed-threshold outcomes; do not select a new rule on this set. As a secondary check score the existing 24 unknown-history library pairs using each locked model and count score increases per setting. No model fitting on library audio, no public release decision.
