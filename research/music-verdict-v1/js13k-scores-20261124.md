## Offline construction and replay

Two fresh Node processes on arm64 macOS produced byte-identical WAVs, each with 5,292,000 frames of stereo, 44.1 kHz, 16-bit PCM. FFmpeg and libsndfile returned identical samples. A direct FLAC preserved all original samples. Encoding the same WAV once with LAME at 128 kb/s and decoding to 16-bit FLAC produced different PCM of exactly the same length. The latter FLAC decodes to precisely the integer samples obtained directly from the intermediate MP3. These files supply a known-history pair for one real work. Every version belongs to the same group. Neither model scored this track. [Construction receipt](island-construction-20261124.json)

The public source snapshot, private render and pair are retained under the following schwarz directories. The analysis uses the source snapshot offline. Acorn 8.15.0 is pinned by content in the snapshot. The render uses Node 24.14.0. Run from the repository root with a fresh output directory.

```sh
set -e
set -o pipefail
base=/Volumes/schwarz/lossytrace/validation
snapshot="$base/js13k-score-metadata-20261124-001"
node scripts/music_verdict_soundbox_sources.mjs "$snapshot" | cmp - research/music-verdict-v1/js13k-scores-20261124.json
out="$base/island-render-replay"
node --random-seed=20260927 scripts/music_verdict_island_render.mjs "$snapshot/island-not-found" "$out"
diff -qr "$base/island-render-20261124-001" "$out"
ffmpeg -nostdin -v error -n -i "$out/score.wav" -map 0:a:0 -map_metadata -1 -c:a flac "$out/direct.flac"
ffmpeg -nostdin -v error -n -i "$out/score.wav" -map 0:a:0 -map_metadata -1 -c:a libmp3lame -b:a 128k -write_xing 1 "$out/intermediate.mp3"
ffmpeg -nostdin -v error -n -i "$out/intermediate.mp3" -map 0:a:0 -map_metadata -1 -c:a flac -sample_fmt s16 "$out/roundtrip.flac"
for file in direct.flac intermediate.mp3 roundtrip.flac; do
    cmp "$out/$file" "$base/island-construction-pair-20261124-001/$file"
done
```
